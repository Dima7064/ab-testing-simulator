# 🛒 A/B Testing Simulator для E-commerce

Интерактивная песочница для практического изучения методологии A/B-тестирования. Проект симулирует реальную воронку интернет-магазина и позволяет на практике столкнуться с типичными ошибками и подводными камнями, с которыми продуктовый аналитик сталкивается в бигтехе.

## 🎯 Чему учит этот проект?

- Как генерировать синтетические данные для воронки (Показ -> Клик -> Корзина -> Заказ -> Оплата).
- Как правильно рассчитывать и интерпретировать Primary и Guardrail метрики.
- Почему нельзя останавливать тест раньше времени (**Peeking**) и что такое **Novelty Effect**.
- Как **Парадокс Симпсона** может исказить результаты, если не смотреть на сегменты.
- Как применять **Multiple Testing** (поправки Бонферрони/FDR), чтобы не найти случайную значимость.
- Как использовать **CUPED** для снижения дисперсии и ускорения тестов.

## 📂 Структура проекта

- `src/generate_data.py` — генератор базовой воронки (без эффектов).
- `src/generate_ab_data.py` — генератор теста с реальным положительным эффектом.
- `src/generate_simpson_data.py` — генератор теста с дисбалансом выборки (Парадокс Симпсона).
- `src/generate_novelty_data.py` — генератор теста с эффектом новизны (Peeking).
- `src/generate_multiple_testing.py` — генератор теста с множеством метрик (p-hacking).
- `src/generate_cuped.py` — генератор данных для применения CUPED.
- `notebooks/` — Jupyter-ноутбуки с разбором каждого кейса.
- `app.py` — интерактивный дашборд на Streamlit.

## 🚀 Как запустить

### 1. Установка зависимостей

```bash
python -m venv .venv

# Для Windows:
.venv\Scripts\activate
# Для Mac/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Генерация данных

Запустите нужный скрипт, например:

```bash
python src/generate_ab_data.py
```

### 3. Запуск интерактивного приложения (Streamlit)

Чтобы поиграть с параметрами теста и увидеть, как меняются p-value и доверительные интервалы:

```bash
streamlit run app.py
```

### 4. Исследование в Jupyter

Откройте ноутбуки в папке `notebooks/`, чтобы увидеть математику и графики.
